Install

One command. It downloads the prebuilt universal app, 2.2 MB for Apple silicon and Intel, and launches it. Nothing to compile, so no Xcode and no Command Line Tools. 

# 1. download, install, launch
curl -fsSL https://snap-it-bheng.vercel.app/install.sh | bash

# 2. allow it to move windows (see the table)

# 3. press cmd alt left on any window. Done.

# coming from Divvy? bring your layouts over
make import-divvy

It lives in the menu bar

No window, no Dock icon, no app switcher entry. After it launches, look for a small rectangle split down the middle at the right of your menu bar. Clicking it is how you reach every layout and Settings.

Nothing to configure

All 16 layouts ship already bound to the Divvy key set, so the app is useful the second it launches. Redraw or rebind any of them later in Settings.

Accessibility, and nothing else

Moving another app's window is the one privileged thing Snap It does, so it is the one permission it asks for. No screen recording, no input monitoring, no network access.

No keylogger in the loop

Shortcuts are registered with the system hot key API, so Snap It is handed the combinations you chose and never sees another keystroke.

The one step macOS will not let an installer do

Snap It asks for Accessibility the moment it launches. Click Open System Settings on that prompt and switch Snap It on. If you dismissed it, here is where it lives on your version.

One file you can read

Settings live in ~/Library/Application Support/SnapIt/config.json. Edit it by hand or use the grid picker in the settings window. Positions are fractions, so a layout means the same thing on a laptop and on a 6K display. 

{
  "gap": 0,
  "grid": { "columns": 6, "rows": 6 },
  "layouts": [
    {
      "id": "left-half",
      "name": "Left Half",
      "frame": { "x": 0, "y": 0, "width": 0.5, "height": 1 },
      "shortcut": "cmd+alt+left"
    }
  ]
}

Why it is this small

Three decisions did most of the work.

Fractions, not pixels

A layout is four numbers between 0 and 1. Every display, every resolution, every external monitor gets the same result with no per screen setup.

The system's own hot keys

No event tap, no polling loop, no helper process. macOS wakes the app only when a registered combination is pressed.

Nothing to configure twice

The menu, the settings window and the JSON file are the same state. Change any one and the other two are already up to date.
